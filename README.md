# Facial Emotion Recognition

Deep learning project focused on facial emotion classification using CNN and ResNet architectures implemented in PyTorch.

## Features
- Exploratory Data Analysis (EDA)
- Image preprocessing
- CNN implementation
- Transfer learning with ResNet18
- Model evaluation and visualization

## Technologies
- Python
- PyTorch
- Google Colab
- NumPy
- Pandas
- Matplotlib

## Dataset
Dataset obtained from Kaggle.
